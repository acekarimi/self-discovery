# Self-Discovery to Master Plan

An interview that figures out who you are and what to build. Claude asks you one question at a time, then writes a profile of who you are, a recommendation on what to focus on first, and a master plan.

Created by Ace Karimi.

## Use it in Claude Code

Run these two commands inside Claude Code:

```
/plugin marketplace add YOUR-GITHUB-USERNAME/self-discovery
/plugin install self-discovery@ace-karimi
```

Then start a new session and say: "Run the self-discovery-master-plan skill on me."

## Use it in the Claude app

Download `self-discovery-master-plan.zip` from this repository. In Claude, go to Customize → Skills, tap +, then Create skill → Upload a skill, and choose the file. Then start a new chat and say: "Run the self-discovery-master-plan skill on me."
